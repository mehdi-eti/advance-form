# advance-form

TypeScript React library for config-driven UI rendering with full IntelliSense support.

## 🚀 Quick Start

```bash
npm install
npm run build
npm run dev
```

## 📦 Monorepo Structure

- **`packages/core`** - Main TypeScript library
- **`apps/example`** - Vite + React example application

## ✨ Features

- 🎯 Config-driven component rendering
- 📝 Full TypeScript IntelliSense
- ✔️ Built-in validation system
- 🚀 Lazy loading for performance
- 🎨 extensible component registry
- 📱 Layout components (Container, Grid, Flex)
- 🌐 React 17+ support
